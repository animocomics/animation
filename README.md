# نمره — دستیار تصحیح اوراق امتحانی

پلتفرم فارسی و RTL برای ساخت آزمون، تعریف کلید و بارم، خواندن عکس/PDF برگه با مدل چندوجهی، تصحیح با API Key، بازبینی شواهد و تأیید نهایی توسط معلم.

> **بدون OCR جداگانه:** تصویر و PDF مستقیم برای OpenAI یا Gemini ارسال می‌شود. خروجی AI پیش‌نویس است؛ نمرهٔ نهایی با معلم است و دقت ۱۰۰٪ وعده داده نمی‌شود.

## امکانات پیاده‌شده

- داشبورد فارسی، آزمون‌ها و جزئیات وضعیت تصحیح
- Wizard چهارمرحله‌ای با ذخیرهٔ خودکار:
  1. مشخصات و سیاست آزمون؛
  2. سؤال‌ها، کلید و بارم؛
  3. عکس/PDF دانش‌آموزان؛
  4. کنترل اتصال و اجرای صف تصحیح.
- ۱۰ نوع سؤال: تستی، چندپاسخی، درست/غلط، جای‌خالی، پاسخ کوتاه، تشریحی، محاسباتی، شکل/نمودار، جورکردن و ترتیب‌دهی
- Rubric تفصیلی، پاسخ‌های جایگزین، نمرهٔ جزئی و قاعدهٔ خطای انتقالی
- آپلود گروهی یا چند فایل برای یک دانش‌آموز؛ پیش‌نمایش فایل اصلی
- اتصال واقعی به:
  - OpenAI Responses API با Structured Outputs؛
  - Gemini GenerateContent با Response Schema.
- آزمایش اتصال و مدل از داخل رابط
- خروجی ساختاریافته شامل رونوشت، شاهد/صفحه، نمرهٔ معیار، دلیل، اعتماد و هشدار
- کنترل سروری نمره‌ها، جمع کل و سقف هر معیار
- تطبیق قطعی تستی‌ها، تشخیص چندگزینه‌ای مبهم و نرمال‌سازی متن فارسی/عربی
- ممیزی دوم هدفمند در حالت متعادل/دقیق
- هشدار ناخوانایی، تصویر بی‌کیفیت، پاسخ مفقود، اعتماد پایین و نزدیکی به مرز قبولی
- اجرای دو برگه به‌صورت هم‌زمان، توقف، ثبت خطای مستقل و تلاش مجدد موارد ناموفق
- صف بازبینی سه‌بخشی: فهرست دانش‌آموز، برگهٔ اصلی، نمره و شواهد
- اصلاح نمره با نگهداری مقدار اولیهٔ AI، رفع هشدار، تأیید/بازکردن مجدد و Audit Trail
- بازخورد معلم، کارنامهٔ چاپی، JSON و CSV با BOM برای Excel
- گزارش میانگین، میانه، قبولی، توزیع، تحلیل هر سؤال و اختلاف ویرایش معلم/AI
- ذخیرهٔ آزمون/نتیجه در LocalStorage و فایل‌ها در IndexedDB
- دادهٔ نمایشی علامت‌دار برای دیدن محصول بدون API Key

## اجرا

نیازمند Node.js 20 یا جدیدتر:

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید. برای دسترسی از شبکه، dev server روی `0.0.0.0` اجرا می‌شود.

```bash
npm test          # تست قواعد نرمال‌سازی و تصحیح
npm run typecheck
npm run build
npm start
```

به متغیر محیطی برای اجرای رابط نیاز نیست. در صفحهٔ **تنظیمات و اتصال** Provider و مدل را انتخاب و API Key را وارد کنید.

## مسیر استفادهٔ واقعی

1. دادهٔ نمایشی را ببینید یا فضای کاری را از تنظیمات پاک کنید.
2. در «تصحیح جدید» آزمون و حد قبولی را بسازید.
3. برای هر سؤال، صورت، کلید و معیارهای مستقل با جمع نمرهٔ برابر وارد کنید.
4. فایل هر دانش‌آموز را به کارت خودش بدهید. در آپلود گروهی هر فایل یک دانش‌آموز جدید می‌شود.
5. در گام آخر API Key را وارد و ترجیحاً «آزمایش اتصال» را بزنید.
6. تصحیح را اجرا کنید. خطای یک برگه بقیهٔ صف را متوقف نمی‌کند.
7. در «بازبینی نمرات» رونوشت و شاهد را با تصویر اصلی مقایسه کنید؛ نمره را در صورت نیاز اصلاح و تأیید کنید.
8. از «گزارش و تحلیل» CSV بگیرید یا کارنامهٔ فردی چاپ کنید.

## امنیت و محدودیت‌های نسخهٔ ۱

- API Key فقط در `SessionStorage` تب نگه‌داری می‌شود؛ در LocalStorage، آزمون و نتیجه ذخیره نمی‌شود. هنگام اجرا به بک‌اند محصول و سپس Provider ارسال می‌شود.
- فایل‌ها در IndexedDB مرورگر و داده‌های ساختاری در LocalStorage همان مرورگر ذخیره می‌شوند. پاک‌کردن دادهٔ سایت آن‌ها را حذف می‌کند.
- این نسخه **تک‌کاربره و بدون احراز هویت** است. برای استقرار مشترک مدرسه به PostgreSQL، Object Storage، صف Worker، احراز هویت، RBAC و سیاست حذف فایل نیاز است.
- برای دادهٔ واقعی دانش‌آموز فقط از استقرار HTTPS و Provider دارای قرارداد/سیاست مناسب استفاده کنید. ارسال فایل به OpenAI/Gemini مشمول سیاست همان سرویس است.
- هزینهٔ مدل از حساب API کاربر کم می‌شود. حالت دقیق برای موارد پرچم‌دار درخواست دوم دارد.
- آپلود هر فایل در UI حداکثر ۱۵MB است. محدودیت مجموع هر درخواست در سرور: حدود ۴۰MB برای OpenAI و ۱۴MB برای Gemini (به‌سبب محدودیت inline payload). فایل‌های بزرگ‌تر باید تقسیم شوند.
- اگر Provider از محیط اجرا در دسترس نباشد، خطای ارتباط نمایش داده می‌شود؛ نتیجهٔ ساختگی جایگزین تصحیح واقعی نمی‌شود.
- «اعتماد مدل» احتمال کالیبره‌شدهٔ درستی نیست. برای آزمون سرنوشت‌ساز، نمونه‌برداری انسانی و کالیبراسیون محلی لازم است.

  grading/                # Wizard، ویرایشگر سؤال و آپلود

lib/
